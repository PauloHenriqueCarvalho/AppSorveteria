# Ideias Futuras para o Sistema de Gestão para Sorveteria

Este documento serve como um repositório para novas ideias e funcionalidades futuras que podem ser incorporadas ao sistema, expandindo suas capacidades.

## 1. Expansões Futuras (Mencionadas na Proposta Original)

- Integração com impressora de cupom fiscal.
- Versão web do painel para celular da dona.
- Integração com iFood (pedidos entram automaticamente).
- Relatório financeiro avançado com custo de produção.

## 2. Outras Ideias e Melhorias

- Módulo de gestão de receitas para produção de sorvetes.
- Notificações push para alertas de estoque baixo no celular da dona.
- Integração com sistemas de pagamento online.
- Funcionalidade de promoções e descontos.
- Dashboard personalizável para a dona com métricas chave.
- Geração de QR Code para comandas ou mesas.
- Gerenciamento de turnos e escalas de funcionários.
