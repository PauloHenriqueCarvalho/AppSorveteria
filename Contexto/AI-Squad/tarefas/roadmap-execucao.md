# Tarefas: Roadmap de Implementação

Lista de tarefas organizadas por prioridade para a execução do projeto.

## Fase 1: Fundação e Core (Semana 1-2)
- [ ] Configurar a estrutura de pastas da Clean Architecture no VS Code.
- [ ] Implementar as entidades de domínio (Produto, Comanda, ItemComanda, Usuario).
- [ ] Definir interfaces de repositório no Domain.
- [ ] Configurar o projeto de Infraestrutura com PostgreSQL.

## Fase 2: Aplicação e Vendas (Semana 3-4)
- [ ] Criar casos de uso para abertura e fechamento de comanda.
- [ ] Implementar lógica de Venda Rápida e Self-Service.
- [ ] Desenvolver a API de autenticação e registro de vendas.

## Fase 3: Mobile e Resiliência (Semana 5-6)
- [ ] Configurar SQLite no projeto .NET MAUI.
- [ ] Criar telas de vendas (Balcão e Venda Rápida).
- [ ] Implementar o serviço de sincronização background.

## Fase 4: Gestão e Estoque (Semana 7-8)
- [ ] Implementar controle de insumos no backend.
- [ ] Criar painel da dona para visualização de estoque e alertas.
- [ ] Desenvolver relatórios básicos de vendas.

## Fase 5: Ajustes e Finalização (Semana 9)
- [ ] Testes de integração entre Mobile e API.
- [ ] Refinamento da interface de usuário.
- [ ] Deploy inicial do banco de dados PostgreSQL.
